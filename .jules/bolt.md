## 2024-05-18 - Replacing useEffect Derived State with useMemo
**Learning:** The `Marketplace.jsx` component was using `useEffect` combined with `useState` to calculate `filteredProducts`. This is a classic React anti-pattern that triggers an initial render with stale data, runs the effect, and then triggers a second render. It also unconditionally cloned arrays. Replacing it with `useMemo` computes the value during the first render, preventing the double-render cycle. Furthermore, array cloning before sorting was deferred until actually needed, reducing memory allocations.
**Action:** When identifying derived state (like filtered lists, searched items), look for `useState` setters called inside `useEffect` that only depend on other state/props. Convert these to synchronous `useMemo` blocks to save a render cycle and prevent UI flickering. Ensure you only clone the source array (`[...array]`) right before a mutating operation like `.sort()` if an earlier `.filter()` hasn't already created a new array instance.
