## 2025-05-30 - Direct string comparison for ISO 8601 date strings vs new Date() inside Array.prototype.sort
**Learning:** For sorting by `created_at` ISO 8601 strings, replacing `new Date(a) - new Date(b)` inside a sort comparator with a direct string comparison `a < b ? 1 : -1` combined with `useMemo` significantly reduces array processing time (from ~440ms to ~27ms in a loop of 10 for 10000 records). Furthermore, chaining `.sort` directly after `.filter` is a safe optimization because `.filter` already allocates a new array instance, removing the need for a redundant spread operation `[...filtered].sort()` which causes extra memory allocations and copying.
**Action:** Always prefer direct string comparisons for sorting ISO 8601 strings. Delay array cloning (`[...array]`) in `useMemo` computations until right before a mutation operation actually requires it, explicitly avoiding the clone if `filter()` was already applied.
