## 2024-05-24 - Optimizing React Derived State in Marketplace
**Learning:** Using `useEffect` + `useState` to derive filtered/sorted arrays from a source `useState` (e.g., in `Marketplace.jsx`) forces a complete double-render cycle of the component tree every time the source data or filters change. Furthermore, indiscriminately cloning large arrays (`[...allProducts]`) at the start of derivation logic causes memory thrashing, especially when the resulting array isn't always mutated (e.g., when a sort isn't applied).
**Action:** Always prefer `useMemo` for derived state to compute values synchronously during render. Delay array cloning operations (`[...array]`) until absolutely necessary—specifically, right before a mutative operation like `.sort()`—to avoid unconditional memory allocations.
