## 2025-05-15 - React List Component Anti-Pattern: Derived State on Render with O(N log N) Array Methods
**Learning:** React components displaying data lists (like `BuyerQueries` and `Marketplace`) are frequently using unconditional array mapping, filtering, and sorting (`[...data].filter().sort()`) directly in the render body. This triggers redundant memory allocation and costly operations (specifically sorting, which parse strings to Dates inside the comparator) on every prop or state change, regardless of whether the list inputs actually changed.
**Action:** When inspecting list components, actively look for derived computations running unconditionally in the render scope. Wrap these in `useMemo`, and replace object instantiation inside iterators (like `new Date()`) with direct primitive comparisons whenever possible to mitigate the compounding performance penalties.
