## 2024-07-01 - React Array Mutation and Date Sorting Insights
**Learning:** In React derived state computations, if you use `.filter()`, it returns a new array instance. Therefore, you do not need to do `[...array].filter().sort()` to maintain immutability; `array.filter().sort()` is safe and avoids an unnecessary memory allocation step before the filter. Furthermore, for sorting ISO 8601 strings (like Supabase `created_at`), direct string comparison (`a < b ? 1 : -1`) is dramatically faster (~95% reduction in time) than parsing strings into `Date` objects inside the comparator.
**Action:** When filtering and sorting sequentially in `useMemo`, omit the spread operator before `.filter()`. Use string comparison for ISO dates to prevent main thread blocking during sort operations.
