## 2024-05-18 - React Derived State Performance
**Learning:** Using `useEffect` to synchronize internal state (like `filteredProducts`) based on prop or query param changes inherently causes a double-render cycle, blocking the main thread longer than necessary. In `Marketplace.jsx`, we discovered this pattern combined with unconditional array spreading (`[...allProducts]`) happening on every render regardless of sorting need, causing unnecessary memory allocation spikes.
**Action:** Always prefer `useMemo` for derived state to compute it synchronously during render. Furthermore, only spread/clone arrays right before executing a mutative operation (like `.sort()`), avoiding cloning entirely if preceding immutable operations (like `.filter()`) already produced a new array reference.
