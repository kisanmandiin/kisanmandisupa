## 2026-08-07 - React Derived State and Array Spread Micro-Optimization
**Learning:** When managing derived state (like filtering/sorting) in React, using `useMemo` prevents double-render cycles compared to `useEffect` + `useState`. Additionally, because `Array.filter()` creates a new array instance, chaining a mutative method like `.sort()` onto a filtered array is safe. Unconditional spreads (e.g., `let filtered = [...allProducts]`) before conditional mutations cause unnecessary memory allocations on every re-render and should be delayed or skipped if the array is already cloned by `.filter()`.
**Action:** When refactoring `useEffect` state synchronization into `useMemo`, conditionally apply array spreading (`[...array]`) only right before a mutation operation (like `.sort()`) and only if the array hasn't already been duplicated by methods like `.filter()`.
