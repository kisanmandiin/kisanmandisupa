## 2026-10-06 - Derived State Double-Render in React
**Learning:** The `Marketplace.jsx` component used a  to synchronize a `filteredProducts` state variable with `allProducts` based on URL search parameters. This forces a double-render cycle (one for parameter changes, another for the state update) which negatively impacts performance when rendering complex components like lists of `ProductCard`s.
**Action:** Use `useMemo` to synchronously compute derived state during render. This prevents unnecessary double-renders. Also, be careful when chaining mutative array methods (like `.sort()`) and clone the array efficiently inside the `useMemo` by keeping track of whether a prior operation (like `.filter()`) already returned a fresh array instance.
