## 2024-05-05 - Avoid Derived State with useEffect\n**Learning:** In Marketplace.jsx, `filteredProducts` was managed with `useState` and updated via `useEffect` whenever filters changed. This caused an unnecessary extra render cycle every time a filter was applied, delaying UI updates and causing extra layout calculations.\n**Action:** Use `useMemo` to synchronously compute derived state during the render cycle, removing the redundant `useState` and `useEffect`.
