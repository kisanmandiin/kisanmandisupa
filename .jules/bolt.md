## 2025-02-14 - Optimize BuyerQueries filtering and sorting
**Learning:** The `BuyerQueries` component was re-calculating `filteredQueries` on every single render by parsing ISO date strings into Date objects for comparison. In React, array methods like `filter` and `sort` on every render with large sets and expensive operations (like `new Date()`) cause significant main thread blocking, which can result in janky UI, especially when typing or triggering re-renders in parent components. Sorting ISO 8601 strings directly (`a < b ? 1 : -1`) is dramatically faster than parsing to dates.
**Action:** Use `useMemo` to memoize the `filteredQueries` calculation so it only runs when `queries`, `filterStatus`, or `sortDate` change. Also, replace `new Date()` parsing with direct string comparison for `created_at` which are ISO 8601 timestamps.
