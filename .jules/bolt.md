## 2024-05-18 - Optimized Array Sorting in Derived State with useMemo
**Learning:** In React components like `Marketplace.jsx`, using `useEffect` and an additional `useState` (like `filteredProducts`) to compute derived state based on dependency changes (e.g. `allProducts`, `category`, `search`) creates a well-known double-render cycle. Furthermore, when computing filtered arrays, applying `.filter()` automatically returns a new array, making subsequent array cloning (`[...array]`) prior to a mutation operation like `.sort()` completely redundant and wasteful of memory.
**Action:** Replace `useEffect` and extra `useState` bindings with `useMemo` for synchronously derived state during the render cycle. When filtering an array, delay operations like `[...array]` cloning until immediately before `.sort()` only if no `.filter()` branch has executed beforehand.
