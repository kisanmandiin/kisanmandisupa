## 2024-05-18 - Optimized Derived State and Sorting
**Learning:** In React components like `Marketplace.jsx`, using a separate `useState` (e.g., `filteredProducts`) updated via a `useEffect` that watches other states (e.g., `allProducts`, `category`, `search`) creates a forced double-render cycle. Furthermore, parsing ISO-8601 strings into `Date` objects on every sort iteration (e.g., in `BuyerQueries.jsx`) is O(N log N) with heavy memory allocations, causing main thread blocking.
**Action:** Replace `useEffect` derived state updates with synchronous `useMemo` blocks to compute the state directly during render. For sorting chronologically by ISO 8601 timestamps, use direct string comparison (e.g., `a < b ? 1 : -1`) which is significantly faster (~96% reduction in execution time) than `new Date()`.
